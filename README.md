# steady

A therapeutic-toolbox PWA: a hub of self-guided emotional-regulation and processing tools (Energy Jar, Personal Timeline, and more), with guest (local-only) and signed-in (Supabase) storage modes. Deployed to GitHub Pages.

## Development

```bash
npm install
npm run dev        # start the Vite dev server
npm run build      # type-check then production build (dist/)
npm run preview    # preview the production build
npm run typecheck  # TypeScript type-check
npm run lint       # ESLint (flat config) + Prettier-friendly
npm test           # Vitest unit/component tests
npm run e2e        # Playwright end-to-end tests
```
